# E-commerce Sales EDA

Exploratory data analysis of the **UCI Online Retail** transactional dataset, using Python and Jupyter Notebook.

## Objectives
- Inspect data quality and prepare transaction records.
- Explore revenue over time.
- Identify top products and countries by revenue.
- Examine sales by weekday and hour.
- Explore customer revenue and cancellation patterns.
- Export cleaned data, charts, and summary tables.

## Dataset
UCI Machine Learning Repository — Online Retail: https://archive.ics.uci.edu/dataset/352/online+retail

The notebook downloads the original ZIP file from UCI when needed, extracts the Excel dataset into `data/`, and processes it locally. Internet access is required for the first run.

## Run locally
1. Clone the repository and open this folder in VS Code.
2. Create and activate a virtual environment.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Open `notebooks/ecommerce_sales_eda.ipynb` in Jupyter or VS Code and run all cells.

Run the notebook from the `notebooks/` folder context so its relative paths resolve as written.

## Important notes
- Revenue is calculated as `Quantity * UnitPrice`; this is transaction line value, not profit.
- Cancellation invoices are analyzed separately and excluded from positive-sales KPIs.
- Customer-level analysis excludes rows with missing customer IDs.
- The source dataset contains transactions from 2010–2011; monthly comparisons should account for incomplete periods.
- Findings and business recommendations should be written only after reviewing the generated results.
